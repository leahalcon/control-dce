# Control semanal DCE

Resumen semanal de las jornadas de capacitación de la División Capacitación y Entrenamiento (DTOCE), generado a partir de la base de datos de tiro. Página estática, solo lectura. Se actualiza los viernes a las 16:00.

`index.html` se genera con `generar_control.py` (Python + openpyxl) a partir de `BASE_DCE_TIRO.xlsx` y `plantilla.html`.
